## 一、场景概述

### 1.1 进入上下文

主角在经历了B节点出租屋的初夜惊魂之后（或者只是正常住了一晚，取决于B节点的选择），第二天上午离开德星路，沿华林路向西步行约300米，抵达华林寺。

进入本节点的三种典型路径：

| 路径 | B节点选择 | 主角状态 |
|------|---------|---------|
| 路径一 | B节点打开窗户查看 → san值-3，勇气+2 | 精神有些恍惚，想找个安静的地方平复。华林寺的钟声从远处传来——像是某种指引 |
| 路径二 | B节点蒙头不管 → 错过便签线索 | 睡了一夜但睡得不好。梦很乱。醒来后想出门走走——华林寺就在附近，不如去看看 |
| 路径三 | B节点打开手机录音 → 获得马蹄声录音 | 手机里那段反复播放的马蹄声让主角无法释怀。那是清兵的马蹄声吗？华林寺——也许那里有人知道什么 |

> **旁白提示（路径三专属）**：手机里那段录音还在。马蹄声。每放一次，你的心跳就快一拍。华林寺是附近最古老的建筑——如果有什么地方能解释你昨晚听到的声音，可能就是那里了。

### 1.2 场景氛围

**色调**：金黄+灰褐。阳光透过老榕树的缝隙洒在华林寺的黄色寺墙上。香火缭绕的青烟在光线中缓慢盘旋。

**氛围关键词**：静谧、神圣、暗流、时间的沉淀

**感官描述**：
- 视觉：黄色寺墙被岁月冲刷出的斑驳纹理；大雄宝殿前青铜香炉中袅袅升起的青烟；五百罗汉堂内昏暗的光线中泥塑罗汉们若隐若现的面孔
- 听觉：寺门外玉器市场摊主的粤语吆喝声（"靓翡翠啊——"）；寺内则是沉甸甸的安静——连自己的脚步声都被某种东西吸收了
- 嗅觉：檀香、灯油、旧木头、古书的纸浆味，混杂着从寺门外飘进来的玉石抛光粉的干涩味道
- 触觉：跨进寺门的瞬间——温度骤降，微凉的空气贴着皮肤

## 二、场景划分

### 2.1 场景一：寺门外 — 华林国际玉器市场

**时间**：约09:00-10:00

#### 场景描写

华林寺的正门并不起眼——它藏在一条窄巷的尽头，被华林国际玉器市场巨大的招牌半遮着。你如果不是特意找，很容易就直接走过去了。

玉器市场里数百个摊位密密麻麻排列着。翡翠、和田玉、玛瑙——各种石头在射灯下闪着温润的光。摊主们用粤语有一搭没一搭地聊着天，偶尔有游客停下来问价，拿起来对着光照一照，放下，走人。

空气中飘着玉石抛光粉的味道，干涩，微甜。和香火味混在一起，变成一种奇异的混合。

寺门口站着几个刚上完香的老人，手里还拿着空了的香筒。他们看起来很正常——和这座寺庙一样正常。和昨天傍晚的荔湾广场一样正常。

*（昨晚的事——墙外的声音，窗户上的手印——是不是自己想多了？）*

#### 寺门细节

华林寺的寺门是传统的岭南寺庙大门样式，门楣上挂着"华林禅寺"匾额，字迹已有些斑驳。门两侧各有一块石碑——一块是广州市文物保护单位的铭牌，另一块是达摩西来初地的纪念石碑。石碑上刻着"西来初地"四个字，旁边小字简述了达摩祖师在此登岸的典故。

如果主角在门前停留片刻——会注意到门上方的横梁上有一根快要被树皮完全包裹的旧铁钉。很旧，锈得很厉害，不像是普通的铁钉。更像是……

*（铜镜的残片？）*

这根铁钉的位置，与S14（恩宁路老照相馆底片）中陈伯陶留下的照片对应——1924年，华林寺门口大树上嵌着一面八卦铜镜。镜子没了，只留下固定的铁钉。那面镜子是刘启盛在三百年后请人嵌进去的——作为监测八棺阵的"传感器"。1993年施工震动让它碎裂了，碎片散落周边建筑。B节点墙角那片铜镜碎片，就是其中一片。

> **跨节点叙事衔接**：此处的铁钉细节在首次进入时只是"有点奇怪"——主角不会多想。如果持有B节点铜镜碎片（`item_broken_mirror`），主角会本能地拿碎片比一下铁钉的直径——吻合。如果是持有S14照相馆底片（`item_photo_negative`），主角可以直观比对出1924年镜子嵌入时的原貌。

### 2.2 场景二：寺门 — 跨越门槛的瞬间

#### 场景描写

你推开半掩的寺门。

跨过门槛的那一步——所有声音同时消失了。不是普通的安静，是沉甸甸的寂静。玉器市场的吆喝声、远处公交车的刹车声、头顶榕树上的鸟叫——全部像被一块厚重的布盖住了一样。

你回头看了看——门外玉器市场的摊主还在说话，嘴在动，但声音传不进来。你能看到他们——他们也能看到你——但那层门框像是一道无形的隔音墙。

*（这不对。）*

不是"安静到能听到针落地"的安静——是声音被主动"吃掉了"的安静。你吸了一口气，能听到自己喉咙里的气流声。你的脚步落在青石板上，声音闷闷的，像踩在棉花上。

跨前一步，进入寺庙。你回头看——门还是那扇门，门框还是那个门框，外面还是那条窄巷、那些摊位。但声音被抽干了。那种沉甸甸的寂静让你下意识地放轻了脚步。

> **san值提醒**：初次进入华林寺的"声音断层"体验不会触发san值变化——它不是恐怖，是"异常"。主角的计算机专业大脑试图用"建筑声学效果"来解释它："也许寺墙特别厚，也许门框设计有问题……"但这个解释自己都不信。

### 2.3 场景三：庭院 — 老和尚扫地

**时间**：约10:00-11:00

#### 场景描写

庭院不大。青石板地面被岁月打磨得光滑发亮。一棵老榕树从院墙边斜斜地长出来，气根垂地。院子中央有一个青铜香炉，手臂粗的香柱插在炉中，青烟缓慢地升起来，在无风的庭院里直直地往上走——没有一丝偏斜。

院子里只有一个人。

一个穿着灰色僧袍的老和尚正在扫地。他大约七十岁上下，动作很慢——慢到像在水中移动。每扫一下，竹扫帚划过青石板的声音在沉甸甸的寂静中被放大，沙——沙——沙——节奏稳定得像一台钟。

你看着他的动作，忽然觉得有点奇怪。

他在扫的并不是"灰尘"。青石板上很干净。干净得像是刚刚被冲洗过。但老和尚还是在一遍一遍地扫——同一个地方——青石板已经扫得发亮了。

沙——沙——沙——。

*（他在扫什么？）*

#### 老和尚详情

| 属性 | 内容 |
|------|------|
| 名称 | 未具名（暂且称为"老和尚"） |
| 年龄 | 约70岁 |
| 身份 | 华林寺扫地僧人，在寺庙已四十余年 |
| 外貌 | 瘦削，脊背微驼但行动并不迟钝。面容平和，眼睛不大却异常清亮——不像七十岁老人的眼睛。手指关节粗大，是常年体力劳动的痕迹。灰色僧袍洗得发白但异常整洁 |
| 性格 | 寡言。说话慢、轻、从不直视人。每一句话都像经过了很长的考虑才说出来。偶尔会微笑——那微笑里面有"知道但不说"的意味 |
| 特殊设定 | 他不是循环者——但他能"感知"循环。四十年的修行让他对时间的变化异常敏感。他察觉到了八棺阵的松动、龙脉的异动、以及"被困在时间里的人"——但他选择了留下。不是被困，是选择留下。他在等——等什么，他自己可能也说不太清楚 |

**老和尚与主角之间的关系递进**：

老和尚并不"认识"主角（在任何正常的意义上）。但主角每一次进入华林寺，身上都会带着比上一轮更强的"时间错位"——跨面道具的气息、上一轮穿越1650年的残留、多次循环累积的时间痕迹。老和尚感知到的不是主角这个人，而是主角身上那种"不属于这个时间"的"味道"。

| 循环次数 | 老和尚的态度 |
|---------|------------|
| cycle=1 | 见主角进来，停下扫帚看了一眼。目光在你的脸上停了一下——比正常看陌生人的时间长了一点点。然后继续扫地。当你走近时，他头也不抬地说了一句："施主看着面熟。" |
| cycle=2 | 见你进来时，他微微颔首。虽然什么都没说，但那个颔首的方向和幅度——和你第一次进寺时一模一样。像是你每次进来，他都站在同一个位置，用同样的角度看着你。 |
| cycle=3+ | 当你走进庭院时，他停下扫帚，双手扶着扫帚柄，平静地看着你。然后说："X施主。"——他直呼了你的姓氏。你的姓。你没有告诉过他。 |
| cycle=5+ | 你还没开口，他就已经停下扫帚了。他把扫帚靠在榕树上，面对你，双手垂在身前，用那种清亮的眼睛看着你，然后问："这次想找到什么？"——不是"想找什么"。是"这次"。他意识到你在循环——虽然他不理解循环是什么。 |

> **关键设计说明**：
> 1. 老和尚的"面熟"感来源于主角跨面带来的时间错位气息——而不是他记得循环。
> 2. 老和尚在第3轮能叫出姓氏，不是因为他恢复了循环的记忆，而是因为主角身上累积的时间痕迹变得越来越"清晰"，他可以"感知"到你是谁——类似于"通感"而非"记忆"。
> 3. 老和尚从不对循环做任何解释。如果有人问他"为什么知道我姓什么"，他会说："风吹过树叶，树叶不需要告诉风自己叫什么。"

### 2.4 场景四：大雄宝殿 — 香火与跪拜

**时间**：约10:30-11:30

#### 场景描写

大雄宝殿是华林寺的主殿。殿内光线昏暗——高窗透进来的阳光被切割成几道细长的光束，照在青铜香炉上，照在佛祖的金身上，照在空气中缓慢飞舞的灰尘上。

殿中央供着三尊大佛——释迦牟尼佛居中，两侧是药师佛和阿弥陀佛。金身已经斑驳，露出底下的泥胎。但这些佛像的面孔——尤其是眼睛——在昏暗的光线中却异常地"生动"。不是恐怖的那种生动。是——好像你在看它们的同时，它们也在看你。

殿前的青铜香炉中，手臂粗的香柱缓慢燃烧，青烟升起来，在高窗的光束中翻滚。那烟的形状比普通香烟更浓、更慢——像液态的丝绸在空气中扭动。

如果你站得足够久——你会注意到那柱香不对劲。所有插在香炉中的香都在燃烧，一根一根，青烟笔直上升。但在香炉最左边，有一根香烧了一半就灭了。不是燃尽的灭——是中断的灭。香柱断口整齐，像是被什么东西"割断"了。但没有人碰过它。

### 6.3 选项组合情况

同一轮C节点内，选项可以组合选择（如先与燕妍交换信息→再探索罗汉堂→最后大雄宝殿跪拜），也可以只选一项后离开。

| 组合 | 是否可行 | 说明 |
|------|---------|------|
| ① → ② → ③ | 可 | 最优探索路径。燕妍陪伴探索罗汉堂（有额外对话）+跪拜恢复san值 |
| ① → ② | 可 | 与燕妍同行但不跪拜 |
| ② → ③ | 可 | 先找到经文，再跪拜。跪拜时经文在背包中微微发热 |
| ② → ① → ③ | 可 | 拿经文时燕妍可能会注意到经文"发热" |
| ① only | 可 | 只与燕妍聊天，不做其他探索 |
| ② only | 可 | 直取经文，不与任何人互动 |
| ③ only | 可 | 只是来拜佛的 |
| ⑤ → ①/②/③ | 可 | 先播放录音给老和尚，再做其他事 |
| ④ only | 可 | 直接离开进入D节点 |
| ④ → 回到C | 不可 | 一旦离开华林寺进入D节点，本轮不可返回C节点 |

### 9.2 功德碑上的隐秘刻痕

如果你用指尖触摸功德碑上"李门陈氏"的刻痕——四次正常刻痕，另外四次似乎不是凿子刻的。是用指甲刮的。

第一次来的时候，你发现了八次"李门陈氏"。但只有前四次是石匠刻的——笔画工整、深度均匀。后面四次指甲刮的——深浅不一，最后一笔拖得很长。

李门陈氏在第八次捐款后不久去世了。去世前，她让儿子扶着她来到功德碑前，用尽最后的力气，用自己的指甲在碑上刻下了最后一次名字。那一次名字刻歪了——因为她的手在抖。不是因为疾病。是因为——她知道那是最后一次。第八棺，最后一次。九次则已完成。

碑的最底部有一道极细的横线——不是刻痕，是指甲拖过的痕迹。那是她在刻完最后一笔后，手指无力滑落的痕迹。

> **这个细节的叙事意义**：
> 李门陈氏知道八棺。她数了一辈子——八口棺，八次捐。她到死都在数。她没有把秘密告诉任何人——只是每年去华林寺捐一次钱。这是一个女人用一辈子完成的仪式。

### 9.3 香炉的"计数痕"

如果你蹲下来看大雄宝殿前的青铜香炉——香炉底部有一圈非常浅的划痕。不是人为的——是长年累月被香柱高温炙烤形成的金属氧化纹。划痕的数量和深度——如果你仔细数——在某个位置刚好和循环次数吻合。你可以说服自己那是巧合。或者不是。

## 十、离开C节点

### 10.1 离开方式

| 离开方式 | 触发 | 目标节点 |
|---------|------|---------|
| 正常离开 | 完成探索后选择"离开华林寺" | D（上下九步行街） |
| 与燕妍同行离开 | 选项①后，燕妍提议"一起去上下九" | D（燕妍同行） |
| 先去玉器市场 | 第3次循环起持有`helped_ergou` | S5（李氏玉器摊）→ D |
| 燕妍提议去邮局 | 与燕妍同行，她提议"去邮局寄明信片" | S6（下九路老邮局）→ D |

### 10.2 每次离开时的跨门体验

跨出寺门的瞬间——声音猛地涌回来。不是一点点恢复——是全部声音在同一瞬间灌进耳朵。你会本能地眨一下眼。然后适应。门外玉器市场还在。摊主还在聊。一切正常。只有你自己知道——刚才你在那道门槛里面度过的那几个小时，发生了一些外面的人永远不会知道的事情。

你回头看了一眼华林寺的匾额。风吹过。匾额上的旧铁钉纹丝不动。然后你转身，朝东走去——朝荔湾广场的方向走去。朝那个被八口棺材压了三百多年的地方走去。
