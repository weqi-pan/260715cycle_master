### 2.6 F节点 — 沙面·珠江边

| 属性 | 详情 |
|------|------|
| **真实地址** | 广州市荔湾区沙面岛（珠江白鹅潭北岸） |
| **与A节点距离** | 约1.2-1.5公里（步行15-20分钟） |
| **环面位置** | 125 |
| **建筑描述** | 沙面是珠江畔的人工小岛，面积约0.3平方公里。曾为英法租界，保留大量19世纪末欧式建筑——浅黄色外墙、绿色百叶窗、铁艺阳台。沿江有步行道、榕树、长椅。岛上有露德天主圣母堂（1890年建） |

| **故事场景** | 珠江水面在深夜漆黑如墨。江边出现"钓鱼人"（民国装扮的灵魂），水面映出1650年广州城墙的倒影。如果帮助过李二狗，会漂来一盏河灯 |
| **可探索区域** | 沙面沿江步道、白鹅潭观景点、露德圣母堂前、沙面岛内部欧式建筑群 |
| **关键地标** | 有钓鱼人出现的江边长椅、白鹅潭三段河道交汇处（阴阳水口）、露德圣母堂门口 |
| **真实历史** | 沙面在1859年成为英法租界，是近代中国半殖民地历史的重要遗址。白鹅潭是珠江广州段最宽阔的水域，三段河道在此交汇，风水上被称为"阴阳水口" |

### 3.2 K节点 — 龙脉裂隙

| 属性 | 详情 |
|------|------|
| **位置** | 非物理空间——存在于任意节点中，当条件满足时可以"穿透"现实进入 |
