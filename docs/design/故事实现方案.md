## 一、故事背景

### 1.1 现实背景

**广州荔湾广场**，位于广州市荔湾区德星路9号，1993年动工，1996年竣工。这座集合了商场与住宅的大型建筑，因其独特的圆弧形顶棚设计与上方8栋塔楼的排列方式，被民间风水爱好者解读为"八棺镇邪"格局。坊间传闻：

- 施工初期，工地上曾出现"五僧三道"在现场念经做法，赶之不去
- 地基之下发现了八口古棺，传说是清代所埋的"八棺压龙牙"风水局——八具死囚之棺，分别压在八颗龙牙之上，以恶人之煞气喂养地龙，镇住龙脉
- 开发商曾试图烧毁棺木，惊动龙脉，此后广场频发坠楼事件
- 招牌上的"广"字在夜间灯光映照下形似"尸"字，"荔湾广场"被戏称为"荔湾尸场"
- 自2004年起，广场发生多起坠楼命案，尤以2014年为甚——全年多起坠亡，包括两名女孩同时跳楼、一天内两人先后坠亡等骇人事件

**历史纵深——庚寅之劫（1650年）**：

清顺治七年（农历庚寅年），平南王尚可喜与靖南王耿继茂率清军围攻广州城长达十个月。1650年11月24日城破之后，清军展开了长达十二天的大屠杀。据多方记载，死亡人数从数万到数十万不等。"杀人十八甫"的民间传说，即是广州人民对清兵沿着西关十八个商业街区（即"十八甫"）逐街屠杀的惨痛记忆。尸骸在东门外焚烧数日，积骸成阜。

荔湾广场所处的西关地区，正好位于当年"十八甫"的核心区域。这片土地之下，埋藏着三百六十八年前的血色记忆。

### 1.2 故事世界观

荔湾广场之下，镇压着一道"时间的裂隙"——这是一道由八棺阵法封印了三百余年的裂缝，连通着1650年那个血流成河的冬天。阵法由明末道士刘启盛与华林寺僧人慧觉联手设下：以八口棺材埋于龙牙之上，将庚寅之劫中最凶戾的怨气封镇于此。

然而1993年的施工破坏了八棺，阵法松动。被镇压了三百余年的怨气与时间裂隙开始渗透，在荔湾广场周围形成了一个封闭的**四天四夜时间循环**。凡是在特定条件下进入这片区域的人，将被困入循环之中，不断重复着从入住到消失的四天。

循环并非简单的重复——每一次循环，裂隙都会扩大一些，历史与现实的边界也会模糊一些。被困者可以在特定节点穿越到1650年的广州，与当年的亲历者互动，带回那个时代的物品与真相，并将在过去的行为"写入"历史，影响下一轮循环。

### 1.3 循环者生态

除了主角和张天民之外，循环中还存在其他"被困者"——有些人只困了几天就消失了（是逃出去了，还是被循环吞噬了？），有些人被困得更久但已经放弃了计数。他们的存在让循环不再是主角一个人的孤岛，而是一个共享但彼此隔离的"囚笼"。

## 二、循环结构设计

### 2.1 循环总览

```
                    莫比乌斯环（200单位）
    
     A(0) ──── B(25) ──── C(50) ──── D(75)
      ↑  ↑                                  │
      │  └────── J(捷径·地宫暗道) ←────────┤
      │                                      ↓
     H(175) ←─── G(150) ←─── F(125) ←─── E(100)
      │                                      │
      └──────────────────────────────────────┘
                  （回到 A = 一次循环完成）
     K(跃迁枢纽·龙脉裂隙) — 独立于环面，条件满足时从任意节点可进入
```

### 2.2 时间线映射：四天四夜

| 节点 | 故事地点 | 环面定位 | 时间 | 主题 |
|------|---------|---------|------|------|
| **A** | 荔湾广场正门 | 0 | 第一天·傍晚 | 抵达/入住 · 循环起点与终点 |
| **B** | 德星路出租屋 | 25 | 第一天·深夜 | 初夜惊魂 · 历史的第一次低语 |
| **C** | 华林寺 | 50 | 第二天·白天 | 寻访古刹 · 佛门的蛛丝马迹 |
| **D** | 上下九步行街 | 75 | 第二天·夜晚 | 鬼市迷踪 · 遇见张天民 |
| **E** | 八棺之地（地下层） | 100 | 第三天·凌晨 | 镜像反转 · 穿越1650年 |
| **F** | 沙面·珠江边 | 125 | 第三天·夜晚 | 江水低语 · 怨气的真相 |
| **G** | 陈家祠 | 150 | 第四天·白天 | 祠堂密录 · 困局的线索 |
| **H** | 康王路·归途 | 175 | 第四天·深夜 | 最后的抉择 · 回到起点 |
| **J** | 地宫暗道（捷径节点） | — | 任何时间 | 直通起点 · 条件触发 |
| **K** | 龙脉裂隙（跃迁枢纽） | — | 任何时间 | 时空跳跃 · 条件触发 |

此外，各主节点之间散落着 **20个子节点**（S1~S20），分布在主节点之间的路径上。子节点为可选探索点，不一定会经过，但每个子节点都包含独特的场景道具、线索碎片或小型事件。

### 2.3 循环开始与结束的衔接设计

**开始节点（A）的设计**：

每次循环从第一天的傍晚开始。主角站在荔湾广场正门前，手中握着出租屋的钥匙。此时的"开始感"源于：
- 手机上的日期始终是 **2018年7月15日，傍晚18:30**
- 天色永远是暮夏的闷热黄昏，夕阳将荔湾广场圆弧形穹顶染成血红色
- 主角心中默念着同一个念头："找到工作了，先租个便宜的地方住下来"
- 记忆模糊——主角只知道自己是来租房的，但之前经历了什么，一片空白

**结束/重置节点（回到A）的设计**：

| 触发方式 | 循环计数 | 描述 |
|----------|---------|------|
| H→A 完整路径 | `cycle_count += 1` | 走完四天全程，自然回到起点 |
| J→A 捷径 | `half_cycle_count += 1` | 从E节点地宫暗道直接穿回起点 |
| K→A 跃迁 | `cycle_count += 1` | 通过龙脉裂隙直接跳回起点 |

**衔接的自然感**：
从H节点走向A节点时，周围的深夜慢慢变成黄昏，手机跳回7月15日18:30。但背包里的某些东西还在（取决于道具属性），记忆碎片留了下来（flags）。结局画面同时也是新的开始。

```
S5帮助李铭宸     → 他可能在后续循环中被卷入+解锁更深层对话
```

## 九、设计原则

1. **每一轮都有新发现**：即使走相同路径，道具/flag递进让选项和文本内容持续变化
2. **选择的影响可见化**：上一轮做的事在下一轮必须有可感知的反馈
3. **信息不对称驱动探索**：核心驱动是"我知道了你不知道的事"
4. **恐怖的本质是未知**：永远保留未解之谜——有些东西知道了反而更可怕
5. **中式恐怖的核心不是鬼怪**：是历史、风水、因果、集体创伤交织的无力感
6. **没有结局 = 无限递进的发现**：循环没有尽头，但每一次都让图景更完整
7. **道具即叙事**：每一个道具都承载着人物故事——护身符是母子最后的联系
8. **跨面共享的意义**：A↔E的道具传递是莫比乌斯环的物理体现
9. **子节点是"世界感"的延伸**：它们不强制经过，但它们的存在让荔湾广场周边变成了一个有呼吸的、真实的世界

## 十、扩展空间

以下内容不在当前大纲范围内，但为未来的深度开发预留接口：

- **八棺全修复结局线**：补完所有阵眼后发生什么？
- **张天民的命运**：他真能逃出循环吗？还是推入另一个更长的循环？
- **燕妍的隐藏身份**：她为什么能"看到"别人看不到的东西？
- **镜像世界的深度**：E节点穿越是否可到达1650年以外的其他时间点？如1993年（八棺被破坏时）、2004年（首次跳楼事件）？
- **其他循环者**：S3地铁站里的循环者是谁？消防栓上刻字的又是谁？循环中还有多少"被困者"？
- **吴应执的直播**：如果他被卷入循环，直播间会发生什么？观众能看到什么？
- **陈伯陶的完整研究**：他在1923-1925年间还发现了什么？日记中被撕掉的那几页在哪？
- **沈半仙身上那块布**：那到底是什么？和循环有关吗？还是只是一个疯子从垃圾堆里捡来的东西？
- **循环是否可以"传染"**：李铭宸会被卷入循环吗？燕妍呢？
- **锦纶会馆的秘密**：为什么那里是循环的唯一死角？
