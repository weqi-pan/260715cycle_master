## 一、荔湾广场都市传说

### 1.1 基本信息

| 项目 | 内容 |
|------|------|
| 名称 | 荔湾广场 |
| 地址 | 广州市荔湾区德星路9号 |
| 建造时间 | 1993年开工，1996年竣工 |
| 开发商 | 广州穗南房产发展有限公司（内地与香港合作企业） |
| 建筑规模 | 14万平方米商场，2000多间商铺，曾居东南亚规模之最 |
| 建筑结构 | 南塔、北塔两栋，由环形露天广场相连；上方8栋住宅塔楼 |
| 1997年房价 | 1.2万/平方米，物业费5元/平方米 |

### 1.2 "八棺镇邪"传说

荔湾广场最著名的都市传说是"八棺镇邪"风水局：

**传说版本一（清代死囚镇龙脉）**：
- 传说清代时，此处埋葬了八具死囚尸体
- 八口棺材的位置正好在"八颗龙牙"之上
- 以恶人之煞气喂养地龙，压制龙脉，防止龙出来害人
- 一旦动了八棺的位置，就会"祸害一方"
- 开发商建造荔湾广场时恰巧动了这八口棺材，惊动了龙脉
- 民间流传该广场"每年都会找8个替死鬼"

**传说版本二（风水师陈振聪）**：
- 开发商黄老板请了风水师陈振聪看地
- 陈振聪本是商人出身，对风水并不精通，靠研读父亲留下的《风水天图布局》转型
- 后成为香港女富豪龚如心的御用风水师，据传骗取32亿港币
- 其风水方法被业内抨击为"邪术"
- 后因伪造遗嘱被判入狱

**施工初期的怪事**：
- 工程队一到工地，就看见"五僧三道"在现场做法
- 工人试图用物品和现金打发他们离开
- 但五僧三道"眼睛微闭，嘴里念着经，一动不动"，根本不理睬

### 1.3 建筑风水解读

| 建筑元素 | 风水解读 |
|---------|---------|
| 圆弧形穹顶 | 形似棺材盖/坟墓顶部 |
| 8栋住宅塔楼 | 俯瞰如八口棺材排列；另说形似8柱香 |
| "广"字招牌 | 夜间灯光映照下形似"尸"字，故被戏称为"荔湾尸场" |
| B1入口电梯 | 入口直通负一层的设计被解读为"直通地下"的不祥象征 |
| 北塔观光电梯 | 胶囊形透明设计，曾是广州最时尚的设计，后成为拍阴森氛围的标志 |
| 商场珠宝店为主 | 民间认为珠宝玉石可以"压邪" |

### 1.4 频发命案时间线

| 时间 | 事件 |
|------|------|

### 1.5 衰落原因（现实因素）

- 产权纠纷：税务拍卖导致产权极度分散，开发商失去管控权
- 管理失控：房东各自为政，商业氛围急剧恶化
- 业主、租户与物业之间矛盾凸显
- 电商冲击：传统实体商场难以竞争
- 商场5-6层的开放设计给了跳楼者可乘之机
- 如今挂满"直播基地"广告，试图转型

## 二、庚寅之劫（1650年广州大屠杀）

### 2.1 基本史实

| 项目 | 内容 |
|------|------|
| 时间 | 1650年（清顺治七年、南明永历四年，农历庚寅年）11月24日至12月5日 |
| 地点 | 广东广州城 |
| 背景 | 清军围攻广州城长达十个月后破城 |
| 主要将领 | 平南王尚可喜、靖南王耿继茂（汉军镶蓝旗） |
| 特殊力量 | 清军动用了荷兰炮手协助攻城 |

### 2.2 死亡人数记载

| 来源 | 记载死亡人数 |
|------|------------|
| 荷兰使臣约翰·纽霍夫 | 八千以上 |
| 美国汉学家魏斐德 | 最多7万 |
| 意大利传教士卫匡国 | 十万 |
| 方恒泰《橡坪诗话》 | 六十余万 |
| 同治《番禺县志》 | 七十万 |

**学术考辨**：学者罗一星（厦门大学博士）指出"七十万"之说不可信，因明末广州府十三县人口总共约40万。他认为"死至几万"的记载较为可靠。广州屠城后不久，南海、番禺两县合计减少45,901人。

### 2.3 屠杀经过

- 《清史稿》记载："继茂与可喜攻下广州，怒其民力守，尽歼其丁壮"
- 卫匡国在《鞑靼战纪》中描述：屠杀从11月24日持续到12月5日，清兵对男女老幼一律残酷杀戮
- 12月6日发布告示宣布封刀
- 纽霍夫记述："全城到处是哀号、屠杀、劫掠"
- 尸体在东门外焚烧多日，直至19世纪仍可见积结成块的骨灰堆
- 顾诚《南明史》记载：僧人真修"募役购薪聚胔于东门外焚之，累骸烬成阜"
- 广东著名文人邝露在此次屠城中遇难

### 2.4 幸存者记载

- 《广州城坊志》引用方恒泰《橡坪诗话》："城前后左右四十里，尽行屠戮……止有七人躲入大南门瓮城关帝庙神像腹中，得免诛戮"
- 城中人士躲入六脉渠约六七千人，适逢天雨，几乎全部溺亡，仅存两人

### 2.5 "杀人十八甫"传说

**十八甫背景**：
- "甫"是广州西关的商业街区单位
- 十八甫是明清时期广州西关的十八个商业街区，从第一甫到第十八甫
- 位于今荔湾区上下九路至人民路一带
- 荔湾广场所在的德星路，正处于十八甫的核心区域

**传说内容**：
- "血洗十八甫"的传说是广州人民对庚寅之劫的可怖记忆
- 清军沿西关商业区逐铺（"甫"）进行屠杀
- 每个"甫"对应一条街，清兵逐街清剿，不放过任何一个角落
- 罗一星指出："'血洗十八甫'的传说，就是广民对这段悲惨历史的可怖回忆"

### 2.6 关键历史人物

| 人物 | 角色 | 备注 |
|------|------|------|
| 尚可喜 | 平南王，清军主将 | 受满清册封，率军南征广东 |

## 四、相关历史人物原型

### 4.1 达摩祖师与华林寺

- 华林寺所在被称为"西来初地"
- 相传禅宗初祖达摩祖师从印度东来中国时，在此地登岸
- 华林寺前身即为纪念达摩而建
- 现存五百罗汉堂为清代建筑

### 4.2 康王信仰

- 康王路路名来源于康保裔
- 康保裔为宋朝名将，抵御辽国入侵时战死
- 民间信仰中将其奉为驱邪避鬼的神祇
- 广东多地有康王庙/康公庙

### 4.3 八棺阵风水概念

"八棺镇邪"是岭南风水文化中的特殊阵法概念：

- **原理**：以八具凶死之人的棺木，安置在特定方位（龙牙），利用凶煞之气反向镇压更强的煞气，属于"以毒攻毒"的风水手法
- **应用场景**：通常用于镇压古战场、万人坑、刑场等大规模死亡造成的地气异常
- **风险**：阵法一旦被破坏，被镇压的煞气（加上棺木本身的凶煞）会双重反噬
- **文化来源**：融合了道教奇门遁甲、风水堪舆术和民间镇邪习俗

## 五、沈半仙人物设计参考

### 5.1 中国民间"疯乞丐/疯僧"形象

沈半仙的外在形象参考了中国传统民间叙事中常见的几类边缘人物：

- **济公（道济和尚）**：南宋时期杭州灵隐寺僧人，行为疯癫不守戒律。民间叙事中他能未卜先知、惩恶扬善，但站在旁观者的视角——他就是一个穿得破破烂烂、说话颠三倒四的疯和尚。只不过他的疯话"碰巧"经常说中
- **街头流浪的精神疾病患者**：在任何时代的城市街头都可能出现的边缘人。他们自言自语，行为怪异，被路人刻意避开。有时候他们的自言自语中会混入一些碎片——一个准确的地名、一个不存在的人名、一个尚未发生的事件——然后听者会感到一阵不安的寒意
- **《红楼梦》中的癞头和尚与跛足道人**：以疯癫形象出现的角色，在关键时刻出现并说出关键的话

**核心设计思路**：
沈半仙不是一个"外表疯癫内在清醒"的传统预言者。他在故事中被设定为一个**真正的精神病人**——他的思维散漫、言辞混乱、在1650年的广州街头流浪，因为偶尔有几句疯话凑巧应验了而被人起了"半仙"这个半开玩笑的外号。从主角（2018年受过现代教育、有基本精神卫生常识的人）的视角来看，他的症状表现最接近精神分裂症谱系障碍。

### 5.2 "不可解释"作为叙事策略

与传统"疯先知"角色不同，沈半仙的"疯"**没有任何超自然解释**。不是全视。不是看见了时间线。不是被天机烧坏了脑子。

他只是疯了。至于他的疯话为什么会偶尔碰对现实——叙事对此保持绝对的沉默。没有答案。

这种"拒绝解释"的叙事策略服务于一个更深的设计目的：

- 玩家（像主角一样）会本能地试图找到一个解释——"他是循环者吗？""他是被困了更久的人吗？"
- 游戏不会确认也不会否认这些猜测
- 沈半仙身上唯一的"异常证据"是一块不属于1650年的布料（牛仔裤碎片）——但这点证据什么也证明不了。一个流浪汉从垃圾堆里捡到奇怪的东西，很正常
- 玩家永远无法确认沈半仙到底是什么。这种"得不到答案的猜测"——比任何解释都更贴合中式恐怖的美学

### 5.3 牛仔裤布料的历史错位

沈半仙身上缠着的破布从外观来看极像牛仔裤布料（denim）。从历史事实来说：牛仔布（denim fabric）起源于19世纪中后期的法国和美国，Levi Strauss在1873年获得铆钉牛仔裤专利。在1650年的中国广州，这种厚实斜纹的蓝色棉织物**根本不存在**。

但游戏不会指出这一点。主角可以拿起来看一看，在心里觉得"这好像牛仔裤啊"——然后主角会把布收起来，什么都不说。游戏也不会弹出任何关于布料的说明。

这一设计参考了"不可靠的历史细节"这一叙事手法——在时代剧中放一个不该存在的物品，不解释，不强调，让细心的观众自己发现并感到不安。

## 六、李二狗后代线素材

### 6.1 李氏家族史（虚构）

根据故事需要构建的李氏家族传承脉络：

| 世代 | 人物（虚构） | 年代 | 事件 |
|------|------------|------|------|
| 第1代 | 李二狗 | 约1625-1651 | 庚寅之劫幸存（如果主角救了他）。在慧觉和刘启盛的帮助下通过密道逃出。临终前叮嘱儿子："欠华林寺和尚一条命。以后李家子孙，每年去华林寺捐香油钱" |
| 第2代 | 李大柱 | 约1650-1720 | 在广州西关做小买卖为生。按照父亲遗命每年去华林寺。听父亲口述了密道的位置和"恩公"的事 |
| 第3-5代 | 李氏族人 | 约1700-1850 | 家族逐渐兴旺，开始做玉器生意。口口相传的故事逐渐加入了"等待恩公"的要素 |
| 第6代 | 李门陈氏 | 约1830-1900 | 李家女性族长。在华林寺功德碑上以"李门陈氏"的名义连续八年捐了八次香油钱——对应八口棺材。她整理了口传故事，第一次写下"若恩公后人来访，以传家玉佩相赠"的祖训 |
| 第7代 | 李玉轩 | 约1860-1930 | 与学者陈伯陶通信。将李氏口传的密道信息提供给陈伯陶研究八棺阵 |
| 第8-10代 | 李氏族人 | 约1890-1980 | 经历战乱和时代变迁，玉器生意断断续续。但祖训和玉佩一直妥善保管 |
| 第11代 | 李铭宸 | 1983- | 华林国际玉器市场的小摊位老板。将祖训当作"老一辈的迷信故事"。直到主角出现 |

### 6.2 玉器市场实地参考

华林国际玉器市场位于华林寺旁，是广州乃至全国知名的珠宝玉器交易市场。市场内数百个摊位密集排列，以翡翠、和田玉、玛瑙等为主。这一设定有真实的地点基础，为S5子节点提供了可信的场景依托。

### 6.3 传家玉佩设计参考

玉佩正面"鱼跃龙门"纹样：中国传统文化中象征逆流而上、突破困境。"鱼"对应李二狗（他在江边"被救"，他的后代在江边"报恩"）。背面"恩"字：全游戏中"善因善果"的核心主题符号。
