# Cycle Master — 故事道具 v1.0

> **用途**：完整记录游戏中所有道具的ID、属性、获取方式、用途和叙事意义。按来源类别分为NPC赠与道具、场景发现道具、子节点专属道具、特殊道具四大类。
> **关联文档**：[故事实现方案.md](故事实现方案.md) | [故事材料.md](故事材料.md) | [故事地图.md](故事地图.md)

## 一、道具分类总览

| 分类 | 数量 | 获取方式 | 特征 |
|------|------|---------|------|
| **NPC赠与道具** | 8件 | 与关键人物互动获得 | 有完整的叙事背景，通常不可替代 |
| **场景发现道具** | 18件 | 在各节点环境中探索获得 | 藏于场景细节中，可能被遗漏 |
| **子节点专属道具** | 8件 | 仅在触发对应子节点时获得 | 轻量级，提供定向辅助 |
| **永恒道具** | 1件 | 循环开始自动持有 | 不可丢弃，不可转移 |
| **特殊道具(非实物)** | 2件 | 知识/flag形式 | 不存在于背包中，以flag记录 |

## 二、NPC赠与道具

### 2.1 阿六的护身符

| 属性 | 内容 |
|------|------|
| **道具ID** | `item_amulet` |
| **类别** | NPC赠与 |
| **获取节点** | E节点（1650年·清兵小卒阿六） |
| **cross_surface** | **true** |
| **视觉描述** | 巴掌大的桃木牌，正面刻着歪歪扭扭的"平安"二字，背面有一道被刀削过的痕迹——那是阿六被征入伍那天，他母亲仓促之间刻下的。木牌边缘因常年被握在手中而磨得光滑发亮。上面沾着几滴三百多年前的暗色痕迹 |
| **获取条件** | 在E节点穿越中轻声靠近阿六并安慰他；或阿六被清兵追逃时遗落，主角拾取 |
| **效果** | san值下降减缓15%（被动）；下一轮循环A节点自动出现在口袋中（`cross_surface=true`） |
| **叙事意义** | 讲述了一个被强征入伍的18岁农家少年和他母亲之间最后的联系。护身符穿越三百六十八年来到主角手中——在每一次循环重置时都会"回到"主角的口袋，仿佛时间本身已经承认了主角是它的新主人 |
| **K节点用途** | 可作为补阵献祭材料，修复一个碎裂的光团 |
| **磨损机制** | 每次跨面传递（A↔E），木牌上的刻痕会加重一道。刻痕达到8道后，护身符在下一轮可能不再出现 |

| **叙事意义** | 这把钥匙是循环中唯一"永恒不变"的东西——不会磨损、不会丢失、每次重置都会回到主角手中。也许这把钥匙本身就是循环的一部分：那个最初"住进502房间"的行为，是启动循环的触发条件 |
