# 全局变量与状态索引

> **用途**：编写各节点故事时的全局参考。所有节点的选项效果、条件判断、道具ID等均以此文件为准。

---

## 一、玩家属性

| 属性ID | 名称 | 初始值 | 范围 | 说明 |
|--------|------|--------|------|------|
| `courage` | 勇气 | 3 | 0-10 | 通过面对危险的选择提升 |
| `sanity` | 理智(san) | 100 | 0-100 | 上限可被永久扣减。低于30时部分选项被锁定 |
| `sanity_max` | san值上限 | 100 | 0-100 | K节点每次使用-1；血月结局-5 |

---

## 二、循环计数

| 变量 | 说明 |
|------|------|
| `cycle_count` | 完整循环次数（H→A或K→A）。初始0 |
| `half_cycle_count` | 半循环次数（E→J→A）。初始0 |
| `total_loops` | `cycle_count + half_cycle_count`。用于判断某些对话的递进 |

## 五、条件表达式语法（供选项使用）

| 表达式 | 示例 | 含义 |
|--------|------|------|
| `has_item:ID` | `has_item:item_amulet` | 持有某道具 |
| `has_flag:FLAG` | `has_flag:helped_ergou` | 存在某flag |
| `attr:属性>=值` | `attr:courage>=5` | 属性比较 |
| `cycle>=N` | `cycle>=3` | 完整循环次数 |
| `half_cycle>=N` | `half_cycle>=1` | 半循环次数 |
| `not:条件` | `not:has_item:item_talisman` | 取反 |
| `and:条件1,条件2` | `and:has_flag:taoist_chant,has_item:item_talisman` | 同时满足 |
| `or:条件1,条件2` | `or:attr:courage>=8,has_item:item_talisman` | 满足其一 |

## 六、选项效果类型

| type | 示例 | 说明 |
|------|------|------|
| `add_item` | `add_item:item_amulet` | 获得道具 |
| `remove_item` | `remove_item:item_talisman` | 消耗道具 |

| `remove_flag` | `remove_flag:qing_exposed` | 移除flag |
| `courage` | `courage:+2` | 勇气变化 |
| `sanity` | `sanity:-5` | san值变化 |
| `sanity_max` | `sanity_max:-1` | san值上限变化 |
| `heal` | `heal:full` | san值恢复 |
| `goto` | `goto:B` | 前往某节点 |

## 七、san值区间对选项可见性的影响

| san值区间 | 效果 |
|-----------|------|
| 70-100 | 所有选项正常 |
| 40-69 | 部分高风险选项文字旁出现"..."（主角在犹豫） |
| 20-39 | 高风险选项不可选（灰色），显示"你太害怕了，做不到" |
| 0-19 | 额外出现"逃避现实"选项（san值越低越容易随机触发幻觉描述） |
