## 一、场景描述

### 1.1 建筑外观与环境

德星路是一条狭窄的老街，两侧挤满了建于上世纪八九十年代的居民楼。路灯昏黄，间隔很大，有些路段完全笼罩在榕树的阴影中。深夜十一点，街上几乎没有人——只有一只橘猫蹲在垃圾桶旁，用发亮的眼睛盯着你。

你租的那栋楼在德星路中段。六层高，灰白色外墙被南方的潮湿侵蚀出一片片水渍，像皮肤病的斑痕。单元门口的铁门锈迹斑斑，门锁早就坏了——用任何硬卡片都能撬开。楼道里没有灯（灯泡碎了没人换），你只能用手机屏幕的光照着往上走。

每一层楼梯转角处都贴满了小广告：疏通下水道、高价回收旧家电、办证、信用贷款……层层叠叠，贴了撕，撕了再贴，墙体上积了一层厚厚的浆糊壳。有些广告纸的边缘翘起来，在穿堂风中发出窸窣的声响——像什么东西在墙纸后面爬行。

五楼。502室。你用钥匙打开门。

### 1.2 房间内部

房间约十五平方米，格局方正。进门左手边是嵌入式的衣柜，柜门合页松了，关不严。右手边靠墙放着一张单人床，床单是前任租客留下的，洗得发白但干净。正对门的是窗户——两扇老式钢窗，玻璃上有一层擦不掉的灰蒙蒙的膜。窗户正对着荔湾广场的北塔。

北塔在月光下的轮廓像一口横卧的巨大棺材。它的外墙在夜晚是深灰色的，只有零星的几扇窗户亮着灯——大部分住户早已搬走。

靠窗放着一张复合板书桌，桌面被烫出了几个圆形的杯印。桌腿不太稳，轻轻一碰就晃。床头柜上有一个搪瓷水杯，杯底还残留着上一位租客倒水后没擦干的水痕。

整个房间有一股淡淡的霉味。不是那种让人反胃的恶臭——更像是老房子在缓慢呼吸时呼出的气息。墙壁上有多处墙皮剥落，露出下面灰黄色的砂浆。有一块剥落处的形状看起来像一个侧脸的人——但你不确定是不是自己看错了。

水龙头在卫生间里——所谓的卫生间其实只是房间一角用玻璃推拉门隔出的一个一平米的小空间。水龙头偶尔会发出"咯——咯——"的怪声，像一根老旧的水管在深夜里被什么东西从内部轻轻敲击。

月租六百。你心想：一分钱一分货。

## 二、时间线推进

### 2.1 23:00-00:30 · 入住与正常时段

```
┌─────────────────────────────────────────────────────┐
│ 时间：23:00 - 00:30                                  │
│ 状态：一切正常                                        │
│ 可操作：整理行李、查看手机、打开窗户通风、搜索房间     │
└─────────────────────────────────────────────────────┘
```

主角放下行李，打开日光灯。灯光闪烁三下后亮了——发出嗡嗡的低频电流声。

如果打开窗户：深夜的凉风涌进来，带着广州夏天特有的潮湿和远处下水道的淡淡腥味。荔湾广场北塔在月光下沉默着。那几扇亮灯的窗户里，看不见任何人影——但你就是觉得有人在看你。

如果搜索房间：可以提前发现一些东西（见第四节道具位置），但此时没有明显的异常事件。

23:45左右，水龙头突然发出一声特别响的"咯——"声，持续了大约十秒，然后归于沉寂。如果你去敲敲水管，声音会停止。但大约五分钟后又开始了。

*（只是老房子的管道问题。很正常。）*

### 2.2 00:30-01:00 · 异常前兆

```
┌─────────────────────────────────────────────────────┐
│ 时间：00:30 - 01:00                                  │
│ 状态：前兆开始出现                                    │
│ 可操作：继续搜索、查看窗外、准备休息                   │
└─────────────────────────────────────────────────────┘
```

00:30左右，窗外传来第一声。很轻——几乎被空调外机的嗡嗡声盖过去了。你以为是楼下有人在打电话，没在意。

00:45。第二声。这次清晰了一些——不是打电话。声音从很远的地方传来，但又好像是从墙壁里面传出来的。模糊的，低沉的，像很多人同时在说话，又像一个人在重复同一句话。

床头柜上的搪瓷水杯开始发出细微的震颤声。水面在微微波动——一圈一圈的涟漪从杯心向外扩散，然后消失，再出现。房间没有风。没有地震。桌子也没晃。只有杯子里的水在晃动。

*（楼下的地铁？但长寿路地铁站距离这里至少三百米。）*

00:55。房间的温度下降了——不是空调的那种冷，是一种"阴冷"，像是有什么看不见的东西在你身后缓缓吸气。

### 2.3 01:00 · 核心异常事件

```
┌─────────────────────────────────────────────────────┐
│ 时间：01:00                                          │
│ 状态：异常事件全面爆发                                │
│ 持续时间：约2-3分钟                                   │
└─────────────────────────────────────────────────────┘
```

凌晨一点整。

墙外突然传来一阵清晰的哭喊声。不是普通话，不是粤语——口音更古老，更像是明末清初的官话夹杂着南方方言。声音里满是恐惧和哀求，像是在对着什么人求饶。不止一个人——男女老少都有，交织在一起，从墙壁的每一寸表面渗透进来。

然后是玻璃上出现手印。

不是从外面按上去的。是雾气在玻璃内侧凝结，形成一个个手掌形状的痕迹。大大小小，有的是成年人的，有的很小——像孩子的手。它们缓慢地从玻璃表面浮现，像有什么看不见的东西正用手掌贴着玻璃，从里往外推。

*它想出去？还是想进来？*

床头柜上的搪瓷水杯震动加剧了。水面的涟漪变成了一道横贯杯面的波纹——静止不动，像被冻结了一样。水温变得冰凉刺骨。

**男性主角专属**：房间的角落里传来一声极轻的叹息——男人的声音，带着克制不住的恐惧。像上一位租客在这间房里留下的最后一口气。

**女性主角专属**：耳边传来极其细微的女声。近到像是说话者的嘴唇几乎贴着你的耳廓。声音里满是颤栗——不是恐惧，是急迫。她在低语。断断续续的字句，听不懂具体内容，但语气像在警告。像在告诉你：不要回头。不要开窗。不要应答。声音持续了大约三十秒，然后突然消失——不是渐弱的，是像被人掐断了一样。

### 2.4 01:03-03:00 · 事件消退

```
┌─────────────────────────────────────────────────────┐
│ 时间：01:03 - 03:00                                  │
│ 状态：异常消退，余韵犹存                              │
│ 可操作：根据此前选择的应对方式，进入不同分支           │
└─────────────────────────────────────────────────────┘
```

哭喊声在一分钟内逐渐远去——不是越来越小声，而是越来越远，像是那群人从墙壁里穿过，走向了另一个什么地方。

玻璃上的雾气手印没有立刻消失。它们停留了大约十分钟——然后缓慢地蒸发，从边缘开始，一点点消散。最后几个消失的手印属于那些最小的——那些孩子的手，在玻璃上停留得比其他的都久。

搪瓷杯里的水恢复了平静。但水面现在静止得不太正常——像一面微缩的镜面，过分的平静。

如果此前选择了"蒙头不管"：事件结束后，你会发现自己紧紧抓着被子，手心全是汗。房间恢复了安静——只有日光灯管的嗡嗡声。但房间似乎比事件之前更冷了。而且……角落里是不是暗了一些？阴影的边缘比以前更深了。

凌晨三点，一切归于平静。你可以选择睡觉——明天还要去华林寺——或者趁着余悸未消，把房间翻个底朝天。

## 三、选项设计

以下为B节点在凌晨1:00异常事件发生时的四个选项。玩家必须在事件进行中做出选择（约120秒倒计时）。

### 选项①：打开窗户查看

```
┌─────────────────────────────────────────────────────┐
│ 选项编号：B_choice_01                                │
│ 选项文本：打开窗户查看外面到底发生了什么              │
│ 短文本：打开窗户                                     │
│ 条件：始终可选                                       │

└─────────────────────────────────────────────────────┘
```

**剧情展开**：

窗户的把手冰凉得刺手。你用力一推——老化的金属铰链发出一声刺耳的尖叫，像是什么东西在抗议被打开。

窗外的北塔轮廓在月光下仍然像一口横卧的棺材。但你看到了——

北塔四楼（如果这是第一轮循环）的某扇窗户里，一个白色的身影一闪而过。不是走过去的——是飘的。悬在半空中，没有脚，没有重量，像一片被风从另一边吹过来的轻纱。它在窗框内停留了大约两秒——你看到了一张模糊的脸，五官被月光漂白得看不清楚——然后它穿过了墙壁，消失在相邻的房间中。

*那不是人。那不是活的东西。*

雾气手印从玻璃上飘了出来——像是被打开了封口，白色的水汽从手印形状的痕迹中升腾起来，在空中汇集成一团模糊的形态。它在你面前短暂地凝聚成了一个人形的轮廓——肩膀、头颅、垂落的手臂——然后散开了。水汽落在你脸上，冰凉的，带着一种说不清的气味——不是霉味，不是腐败，是某种更深层的、混合着檀香和铁锈的气息。

**效果**：
- `courage`: +2
- `sanity`: -3
- `set_flag`: `ghost_lady_seen`（注意到白衣女子身影）
- 此后——这扇窗户在每一轮循环中都会亮着灯。北塔的那扇窗户。不管白天黑夜。即使整栋北塔的灯都熄了，那扇窗还是亮着的。
- 第2轮起：白影的位置会向主角靠近一层——5楼窗→4楼窗→3楼窗→……（每多触发一次，白影在下一轮离主角的楼层更近一层）

**跨循环持久效果**：
- B节点"白影追踪"计数器+1（每次触发后下一轮白影靠近一层）
- 如果白影到达"与主角同层"——即出现在502室正对面的北塔窗户——触发特殊事件（见第五节）

### 选项②：蒙头不管

```
┌─────────────────────────────────────────────────────┐
│ 选项编号：B_choice_02                                │
│ 选项文本：蒙上被子——不听、不看、不回应               │
│ 短文本：蒙头不管                                     │
│ 条件：始终可选                                       │
│ 下一节点：B（停留，异常消退后可搜索房间）              │

└─────────────────────────────────────────────────────┘
```

**剧情展开**：

你把被子蒙过头顶。夏被很薄，但你把它裹得紧紧的——像小时候以为只要被子里就是安全的。

外面的哭喊声被被子过滤得闷了一些，但依然清晰。你闭上眼睛，咬紧牙关。

*（不要听。不要想。天亮了一切就好了。）*

不知道过了多久——也许五分钟，也许二十分钟——声音消失了。你掀开被子，房间里一切如常。日光灯依旧嗡嗡响。搪瓷杯里的水恢复了平静。窗户上的手印已经消退得无影无踪。

你活过了今晚。什么都没有发生。

但房间允许你搜索了。

**效果**：
- 无属性变化
- 异常事件"安然度过"
- 解锁"搜索房间"子场景

**搜索房间可发现**：

**a) 床底 —— 警告便签**：
床底下积了一层薄灰。用手电筒照着扫过去——角落里有一张黄色的便签纸，被揉皱了又展开。上面用圆珠笔写了三遍同一句话：

> 不要看窗外
> 不要看窗外
> 不要看窗外

第一遍是端正的楷书。第二遍笔迹开始潦草。第三遍几乎划穿了纸——字迹歪斜，力透纸背。便签纸的背面还有一行更小的字，像是后来补充的：

> 对不起我没忍住。第一晚就看了。它记住我了。

**获取道具**: `item_warning_note`
**效果**: `sanity-1`（意识到不止自己经历过），`set_flag: knew_previous_tenant`

**b) 衣柜顶 —— 旧报纸**：
衣柜顶部积了厚厚一层灰。你踮起脚尖摸到了一卷发黄发脆的东西——一份剪报，从1993年9月的《广州日报》上剪下来的。纸张已经脆得边缘一碰就碎。

标题：

> **荔湾广场工地发生不明塌方 三名工人失踪**
>
> 本报讯 昨日下午，荔湾广场施工工地B1层发生局部塌方。据现场工人称，施工中发现了不明地下空间，内有砖石结构。施工方随即进行了回填处理。然而回填后三名工人下落不明，截至发稿时搜救仍在进行中。
>
> 一名不愿透露姓名的工人称："挖到的东西不正常。不是墓，比墓深得多。墙上的砖是清朝的，但砖缝里的灰浆还没干。"

剪报被谁放在这里的？上一位租客？还是更早之前的人？502室的月租是六百——在这个地段，便宜得不正常。你已经知道原因了。

**获取道具**: `item_old_newspaper`
**效果**: 提供E节点地下穹顶的准确位置线索

**c) 可选额外搜索**：
搜索书桌抽屉：找到一张空白信纸和几根生锈的回形针（无特殊价值，但可以用于在后续节点中留纸条给下一轮循环的自己）。
搜索衣柜底部：角落有几根很长的黑色头发——不是主角的（增加不安感，无道具）。

### 选项③：打开手机录音

```
┌─────────────────────────────────────────────────────┐
│ 选项编号：B_choice_03                                │
│ 选项文本：打开手机录音功能——记录下这个声音            │

│ 条件：始终可选                                       │
│ 下一节点：B（停留）                                   │

└─────────────────────────────────────────────────────┘
```

**剧情展开**：

你掏出手机——手在发抖，花了两次才解锁屏幕——点开录音APP，按下那个红色的圆点。

手机屏幕上的声波开始跳动。你把它举高，对准窗户的方向。

录了大约四十秒。哭喊声在录音的最初几秒是最清晰的——然后开始掺杂进一些别的声音：

- 马蹄铁在石板路上敲击的声音——清脆，有节奏，由远及近
- 金属碰撞——像盔甲的甲片在摩擦
- 火烧木头的噼啪声
- 远处某个人在喊一个名字——不是哭喊，是指令。一个男人的声音，在中气十足地喊着什么

*这些声音不是从窗外传来的。它们像是在墙内部——在这栋楼的砖缝里，在三百年来的每一层涂料之下，被人遗忘但从未消失。*

录音结束。回放时——声音比实际听到的更清晰。手机的话筒没有耳朵会害怕，它忠实地记录了一切。

如果你在C节点将这段录音播放给华林寺那位扫地的老和尚听——他会沉默很久，然后说：

> "这是顺治七年十一月。清兵入城的号令。年轻人，你录到了三百六十八年前的东西。"

**效果**：
- 获得音频文件："B节点·凌晨一点的墙中之声"（存于手机中，非实物道具，但可作为信息在C节点触发老和尚的特殊对话）
- `sanity: -1`
- `courage: +1`（你在恐惧中保持了记录者的冷静）
- 在C节点播放给老和尚听：解锁隐藏对话"慧觉的口述史"，获得额外关于八棺阵由来的信息


## 五、跨循环变化详细设定

### 5.1 第1轮循环

- 一切正常。异常事件强度为基准值。
- 所有四个选项均可触发（选项④除外，条件不满足）。
- 如果触发选项①（开窗看）：白影出现在北塔5楼窗户（与502室同层）。
- 房间搜索产出的道具正常刷新：便签纸存在于床底（每轮重置），旧报纸存在于衣柜顶（首次获取后跨循环保留但不再生成）。

### 5.2 第2轮循环

**如果上一轮触发过白影**：
- 白影的位置向主角靠近一层——本次循环中它出现在**4楼**的窗户里。
- 主角有一瞬间的既视感：站在502窗前时，会隐约觉得那扇窗户有个模糊的白点——在看自己。
- 描述文本微调：月光下的北塔不再是"像棺材"——现在它是"像正在缓慢苏醒的棺材"。你注意到塔楼的轮廓似乎微微变形了。

**如果上一轮选择了蒙头不管**：
- 房间开始出现水渍。墙皮剥落处下方的墙壁上，水渍的形状越来越像一张人脸——额头、鼻子、嘴唇的轮廓隐约浮现。角度对了之后——又只是普通的水渍。
- 衣柜里那几根头发的长度——似乎比上一轮长了。
- 墙面水渍在一个固定位置（右下角踢脚线）反复出现——干燥→再渗水→再干燥——循环数次。这是铜镜碎片即将出现的征兆。

**如果上一轮选择了手机录音**：
- 凌晨1:00事件中，水杯的震动比上一轮更剧烈。水差点溅出来。
- 墙上的手印多了一双——很小，非常小，像是婴儿的手。

### 5.3 第3轮及以后

**白影追踪（持续触发选项①）**：
- 白影的位置持续靠近。每轮循环向主角靠近一层。
- 第3轮：白影在3楼。你可以用肉眼辨认出那是一个穿白色长裙的身影。裙摆很长——长得不自然，拖在身后根本看不到尽头。
- 如果白影到达"1楼"（即北塔的最底层，与地面齐平），下一轮循环白影将不再出现在北塔——而是出现在502室窗外的防火梯上。离你的窗户不到三米。
- **极端情况——白影进入502室**：如果不采取任何措施、持续多轮触发选项①——某一次循环中，打开窗户后，白影不再是"在对面楼"，而是出现在你房间的角落里。你不会死。它只是看着你。然后在下一轮循环中消失。但你的墙壁上会留下一道怎么都洗不掉的水痕——一个人形的水痕。

**蒙头不管的积累（持续触发选项②）**：
- 连续两轮蒙头：墙角踢脚线缝隙中出现铜镜碎片（`item_broken_mirror`）。水渍干燥后在缝隙中留下一块巴掌大的铜镜碎片——背面有模糊的八卦纹饰。这块碎片摸起来比房间里的任何东西都凉——冰凉的凉，就像刚从深水里捞出来。
- 连续三轮蒙头：房间的温度在晚上十一点后就明显下降。你在房间里能看到自己呼出的白气——七月的广州，室内冷到能呼出白气。
- 墙面上的人脸水渍越来越清晰。第四轮时——你能看出来那是一个女人的侧脸。她闭着眼睛。但嘴唇是微微张开的，像在说"别"。
- 床底的黑暗在蔓延。床底的阴影边缘不再清晰——它像墨水一样，以肉眼很难察觉的速度向外扩张。如果你用尺子量会发现：每天扩张大约两厘米。

**手机录音的积累（持续触发选项③）**：
- 录音质量逐轮提升。墙里的声音越来越清晰——不再只是哭喊和马蹄声。第3轮起，你可以录到具体的词句——"将军有令""不留活口""搜第十一甫"。这些碎片化的清兵指令可以在E节点穿越后用来确认自身所处的精确时间点。
- 第4轮起，你录到一个女声在说一串数字——"3517149"。如果将这串数字尝试作为坐标、密码或其他线索——它指向荔湾广场北塔的精确经纬度（北纬23°07'17"，东经113°14'9"——但这是暗码，需要到G节点翻阅资料才能破解）。

## 十、叙事设计笔记

### 10.1 本节点的叙事功能

B节点是玩家在游戏中遇到的第一个"异常事件"。它的设计目标：

1. **建立威胁感但不伤害玩家**：异常事件是"展示"而非"攻击"。手印、哭喊声、水杯震动——它们都在说"这里不对劲"，但它们不会直接伤害主角。这是引导玩家进入"这个世界有问题"认知的第一步。
2. **提供信息线索**：旧报纸连接到故事的核心背景（1993年施工事故→八棺阵），警告便签暗示上任租客的命运。
3. **建立跨循环后果**：白影追踪机制让玩家的每次选择都有持久意义。选项①不是一次性的——它会"记住你"。
4. **性别差异的首次体现**：女性主角在502室听到的低语——这是第一次让性别成为游戏体验的一部分。这个低语的来源不会在B节点揭示。

### 10.2 恐怖设计原则

- **展示，而非攻击**：异常事件让玩家感到不安，但不损害属性（除选项带来的san值下降）。恐怖来自"不知道它要干什么"，而非"它要伤害你"。
- **克制的文字**：使用中性、冷静的描述语调。恐怖效果来自细节的不对劲（"水杯的涟漪静止了"）而非血腥词汇。
- **留白**：白影的身份、床底那东西的本质、便签上第三遍为什么划穿了纸——都不解释。玩家的想象比任何文字都更恐怖。

### 10.3 与其他节点的叙事关联

| 关联节点 | 关联内容 |
|---------|---------|
| A | 出租屋钥匙（永恒道具）；白影在A节点前奏中有微弱预示（如果上一轮触发过） |
| C | 手机录音可播放给老和尚听；警告便签可触发燕妍的对话（"你这房间太便宜了，肯定有问题"） |
| D | 鬼市中清代残影与B节点听到的哭喊声来自同一批人；持有旧报纸可触发张天民的额外评论 |
| E | 铜镜碎片在穿越时可映出隐藏入口；白影在1650年有对应人物（flag `ghost_lady_seen`） |
| H | 如果白影追踪持续到极端（flag `ghost_lady_met`），H节点的归途上将看到她在康王路尽头等你——然后消失 |
