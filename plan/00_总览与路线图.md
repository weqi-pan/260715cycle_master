# Cycle Master — 开发总览与路线图

> **项目名称**：Cycle Master / 荔湾·四日轮回  
> **开发周期**：约 20-24 周（5-6 个月，单人开发）  
> **最后更新**：2026-07-18  
> **关联文档**：[技术实现方案](../design_docs/技术实现方案.md) | [故事实现方案](../design_docs/故事实现方案.md)

---

## 一、开发阶段总览

| 阶段 | 名称 | 工期 | 核心交付物 | 里程碑 |
|------|------|------|-----------|--------|
| **Phase 0** | 项目骨架与环境搭建 | 1 周 | 前后端项目骨架、开发规范 | 前后端本地可运行 |
| **Phase 1** | 数据层与数据库 | 2 周 | 完整数据模型、seed data、导入脚本 | 数据库建表+种子数据可导入 |
| **Phase 2** | 图引擎核心 | 3 周 | 图加载、条件求值、引擎主循环、特殊路由 | 引擎单元测试全通过 |
| **Phase 3** | 游戏 API 与后端集成 | 2 周 | 全部 REST API、存档系统、后端集成测试 | 8 主节点环形 demo 可跑通 |
| **Phase 4** | 前端游戏播放器 | 4 周 | 游戏播放器全部组件、莫比乌斯小地图 | 完整循环可游玩 |
| **Phase 5** | 可视化编辑器 | 4 周 | Cytoscape 图编辑器、属性面板 | 可编辑/创建完整节点体系 |
| **Phase 6** | 故事数据导入与内容 | 3 周 | 30 节点 100+选择 JSON、条件/道具/flag 数据 | 全部故事内容可游玩 |
| **Phase 7** | 打磨测试与桌面打包 | 3 周 | 动画、音效、Tauri 打包、测试报告 | 可发行版本 |

---

## 二、全局依赖关系

```
Phase 0 (骨架) ──→ Phase 1 (数据层) ──→ Phase 2 (引擎) ──→ Phase 3 (API)
                                                                    │
                                                                    ↓
                    Phase 5 (编辑器) ←── Phase 4 (播放器) ←─────────┘
                                           │
                                           ↓
                    Phase 6 (故事数据) ──→ Phase 7 (打磨→发行)
```

- **Phase 0-3** 严格串行，前一步的输出是后一步的输入
- **Phase 4 和 Phase 5** 可以部分并行（播放器的状态管理层完成后，编辑器就可开始）
- **Phase 6** 需要 Phase 5（编辑器）来录入故事内容，但也可通过手写 JSON 先行
- **Phase 7** 需要 Phase 4 + Phase 6 内容就绪

## 三、技术栈总览

| 层 | 技术 | 版本要求 |
|---|---|---|
| 前端框架 | Vue 3 + Vite | Vue ≥ 3.4, Vite ≥ 5 |
| 前端语言 | TypeScript | ≥ 5.0 |
| UI 组件库 | Element Plus | ≥ 2.5 |
| 图渲染（编辑画布） | Cytoscape.js | ≥ 3.28 |
| 图渲染（游戏小地图） | 手写 SVG | - |
| 状态管理 | Pinia | ≥ 2.1 |
| 样式方案 | SCSS | - |
| 后端框架 | FastAPI | ≥ 0.110 |
| ORM | SQLAlchemy | ≥ 2.0 |
| 数据校验 | Pydantic | ≥ 2.5 |
| 数据库 | SQLite | ≥ 3.35 |
| 桌面打包 | Tauri | 2.x |

## 六、风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| 图引擎复杂度超出预期 | 中 | 高 | Phase 2 预留 3 周并可延长至 4 周 |
| 条件表达式解析器边界情况 | 中 | 中 | 提前编写完整测试矩阵 |
| Cytoscape 环形布局定制 | 高 | 中 | Phase 5 先做原型验证 |
| 前端状态管理复杂度 | 中 | 中 | Pinia 分 store 模块化设计 |
| Tauri 打包兼容问题 | 低 | 低 | Phase 7 末尾预留，可降级为纯 Web |
| 故事内容创作进度 | 中 | 高 | Phase 6 先导入手写 JSON，编辑器可后补 |
