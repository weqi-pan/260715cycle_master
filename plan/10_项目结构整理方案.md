# Cycle Master — 项目结构整理方案

> **目标**：对全项目（前端、后端、数据、文档、测试、配置）进行一次系统性整理，建立清晰、可维护的"项目地基"。
> **原则**：代码与数据分离、源码与生成物分离、文档归类统一、测试层级清晰、遵循行业惯例。

---

## 一、当前问题诊断

### 1.1 根目录臃肿（14 个条目）

```
现状：
├── .claude/         ← 配置
├── .git/            ← 配置
├── .gitignore       ← 配置
├── .pytest_cache/   ← 缓存（游离）
├── .superpowers/    ← 配置（内含 36 个历史 task 文件）
├── README.md        ← 文档
├── assets/          ← 空目录
├── backend/         ← 源码
├── data/            ← 空目录
├── design_docs/     ← 设计文档（与 story_data 内容重叠）
├── frontend/        ← 源码
├── plan/            ← 开发计划（23 个文件平铺）
├── scripts/         ← 工具脚本
├── story_data/      ← 游戏数据
└── tests/           ← E2E 测试
```

### 1.2 后端问题

| 问题 | 详情 |
|------|------|
| **数据库文件位置错误** | `backend/cycle_master.db` 是运行时生成数据，不应在源码目录 |
| **import_story.py 位置不当** | 放在 `backend/` 根目录，与 `app/` 平级，应归入 `scripts/` |
| **__init__.py 全部空白** | 5 个空文件，无包级别文档 |
| **缺少 requirements.txt** | 依赖隐式存在于 venv，新人无法一键安装 |
| **测试分散** | `backend/tests/` (单测) 与根目录 `tests/e2e/` (E2E) 分离 |

### 1.3 前端问题

| 问题 | 详情 |
|------|------|
| **.pytest_cache 污染** | `frontend/.pytest_cache/` 是误放的 Python 测试缓存 |
| **package-lock.json 被 gitignore** | 锁定文件应该提交以保证可复现构建 |
| **缺少 .eslintrc / .prettierrc** | 无代码风格统一配置 |
| **src/components/ 缺少 shared/ 分类** | 未来会出现播放器和编辑器共用的组件 |
| **src/ 缺少 composables/ 目录** | 组合式函数无处放置 |

### 1.4 数据与文档问题

| 问题 | 详情 |
|------|------|
| **同类内容分散两处** | `design_docs/节点具体故事/` 与 `story_data/05_nodes/` 描述同一批节点 |
| **plan/ 内部混乱** | 23 个文件平铺：9 个阶段计划 + 8 个实施方案 + 5 个测试清单 + 1 个体检报告 |
| **assets/ 空目录** | 预留给游戏资源但至今为空，位置待商榷 |
| **data/ 空目录** | 预留给数据但至今未使用 |

### 1.5 配置与工具问题

| 问题 | 详情 |
|------|------|
| **.superpowers/sdd/ 积攒 36 个历史文件** | 开发过程中的 task brief/report/review，完成使命后可归档 |
| **缺少 VS Code 工作区配置** | 无 `.vscode/settings.json`（已 gitignore 但可提供 `.vscode/` 推荐配置） |
| **scripts/ 使用硬编码路径** | `start-backend.sh` 硬编码 `./venv/Scripts/python.exe` |
| **缺少 CHANGELOG** | 无版本变更记录 |

## 三、变更清单（按执行顺序）

### 阶段 A：数据整合（`data/`）

| # | 操作 | 源 → 目标 | 影响文件 |

| A3 | 移动静态资源 | `assets/` → `data/assets/` | main.py StaticFiles mount, .gitignore |
| A4 | 创建导出目录 | 新建 `data/exports/` | .gitignore |

## 四、影响范围矩阵

| 变更类型 | 文件数 | 风险等级 | 说明 |
|---------|--------|---------|------|
| 目录移动（git mv） | ~100+ | **低** | Git 自动追踪重命名 |
| 路径常量更新 | 1 (paths.py) | **中** | 集中修改，一处改全局生效 |
| 交叉引用修正 | ~10 (plan/*.md) | **中** | Markdown 内相对链接 |
| 新增文件 | ~10 | **低** | 纯增量，不影响现有功能 |
| 删除/清理 | ~5 | **低** | 仅清理缓存和空目录 |
