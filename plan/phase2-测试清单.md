## 1. 状态持久化

### 1.1 Flag 链式解锁
- [ ] 打开游戏，A 节点应显示 **3 个选项**（办理入住 / 周边转转 / 查看租房信息）
- [ ] 点击「先在周边转转」→ 出现过渡文本覆盖层，点击关闭
- [ ] 关闭后应看到 **更多选项出现**（观察铜狮、检查台阶、撬出铜钱、前往B1入口、走小巷）
- [ ] 点击「观察铜狮底座刻字」→ 文字描述铜狮刻字
- [ ] 关闭后出现新选项「拓印铜狮底座刻字」
- [ ] 点击「拓印铜狮底座刻字」→ 获得道具，顶部状态栏背包区出现「铜狮底座拓片」

### 1.2 道具获取
- [ ] 点击「检查台阶砖缝」→ 文字描述砖缝
- [ ] 点击「撬出砖缝里的铜钱」→ 获得「清代顺治通宝」，背包显示
- [ ] 再次进入周边探索 → 铜钱选项显示为已获取（条件 `not:has_item:item_qing_coin` 生效）

### 1.3 属性变化
- [ ] 点击「检查口袋里的护身符」（前提：持有护身符道具）→ SAN 值 +3，状态栏数字变化
- [ ] 后续选择中如有 `damage` 效果 → 属性值下降，低于阈值时变红闪烁

## 2. 环形路径遍历

- [ ] A 节点点击「办理入住」→ 进入 B 节点（德星路出租屋）
- [ ] B 节点出现 4+ 个选项（打开窗户 / 蒙头不管 / 手机录音 / 前往华林寺）
- [ ] 点击「前往华林寺」→ 进入 C 节点
- [ ] C 节点 → D 节点 → E 节点 → F 节点 → G 节点 → H 节点
- [ ] H 节点有选项回到 A → A 节点时出现「第 X 次循环完成」提示
- [ ] 循环计数（顶部状态栏）应递增

- [ ] 任意节点（如 A），获得 `taoist_chant` flag 后，应出现特殊选项「踏入突然出现的裂隙」
- [ ] 点击跃迁 → 进入 K 节点（龙脉裂隙，灰白虚空描述）
- [ ] K 节点显示 8 个主节点跃迁目标 + 献祭道具选项
