## 已完成迁移

- 节点与选项内聚到同一个 v2 节点文件。
- `{{#if}} / {{else}} / {{/if}}` 转换为内容块 `when` 条件。
- `[sanity -N]`、`[flag: ...]`、`[获得道具：...]` 等展示标记由结构化 effects 承担，不再混入玩家文本。
- `stay / travel / shortcut / warp` 路由模式明确化。
- NPC 中文显示名转换为稳定 `speaker_id`。
- 对所有节点正文、循环变体和选择结果中的引号段落完成分类审计：现场发言转为 `dialogue`，文献、刻字、标题和内心引述保留为 `narration`。
- 人物现场发言按“台词—动作—台词”拆成原子块；`dialogue` 不再保留外层引号或夹带动作叙述。
- `player` 对话固定显示在右侧，其余 NPC 固定在左侧。
- 补齐 S3、S4、S5、S19、S20 的正式入口，图严格校验无不可达节点。
- 运行 API 已直接返回 `entry_blocks` 与 `result_blocks`；实时验证 C_choice_01 结果为 10 个原子块，开头顺序为 `narration → dialogue → narration → dialogue`。
- `{{cycle_count}}` 与 `{{half_cycle_count}}` 由后端白名单插值，未知变量在 schema 阶段拒绝。
- 正式 v2 替换前的完整数据已备份到 `tmp/story_data_v2_before_atomic_20260720/`。
